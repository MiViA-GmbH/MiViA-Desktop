# Gate retro

Friction with a gate goes here instead of loosening the gate. Each entry: rule id, file, why it hurt, proposed change. Known-limit shortcuts use the rule id `shortcut` with the limit and the trigger for an upgrade. Entries are reviewed in retro sessions.
